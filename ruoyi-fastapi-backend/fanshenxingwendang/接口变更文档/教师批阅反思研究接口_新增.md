# 接口变更文档：教师批阅反思研究模块（新增）

> **版本**：V1.0
> **日期**：2026-06-17
> **变更人**：后端
> **变更类型**：**新增模块**（6 个接口）
> **关联设计**：`四区研究实现逻辑/教师批阅反思研究模块_设计方案.md`
> **新建数据表**：`edu_review`、`edu_review_dialogue`（见 `sql/edu_review.sql`）

---

## 一、模块概述

教师按「班级 / 任务 / 自研课题」查看学生提交的反思性研究结果，完成「**AI（裁判模型）先评论 → 老师针对学生结论点评**」的批阅闭环。

- 批阅对象：一条学习记录（`edu_learning_record`）的反思区成果（按决策分条）+ 四区上下文。
- AI 评论：复用 RAG + LLM，但**强制使用与学生侧（model_id=1）不同的裁判模型**（`task.review_model_id` → `sys_config` 默认回落）。
- 老师点评：评分 + 评语，联动回写 `edu_evaluation` 反思维度（不计算总分、不改 record 状态）。
- 数据范围：教师仅能看自己 `edu_teacher_class` 所管班级的学生；admin 不限。
- 自动触发：学生提交（record→submitted）时后台异步生成首版 AI 评论。

## 二、接口清单（`/learning/review`）

| 方法 | 路径 | 功能 | 权限 |
|---|---|---|---|
| GET | `/learning/review/records` | 教师批阅列表（多维筛选+分页） | teacher / admin |
| GET | `/learning/review/detail/{record_id}` | 批阅详情（四区+反思列表+批阅数据） | teacher / admin |
| POST | `/learning/review/ai-comment/{record_id}` | 生成/重新生成 AI 评论（超时~60s） | teacher / admin |
| POST | `/learning/review/ai-comment/stream/{record_id}` | 流式生成 AI 评论（SSE） | teacher / admin |
| PUT | `/learning/review/comment/{record_id}` | 老师提交/更新点评 | teacher / admin |
| GET | `/learning/review/ai-comment-history/{record_id}` | AI 评论历史版本 | teacher / admin |

## 三、各接口详细定义

### ① GET `/learning/review/records` —— 批阅列表

**查询参数**（Query，全部可选）：

| 参数 | 类型 | 说明 |
|---|---|---|
| `classId` | int | 班级ID（精确匹配） |
| `taskId` | int | 任务/课题ID（精确匹配） |
| `creatorType` | string | `'0'`教学任务 / `'1'`自研课题 |
| `studentName` | string | 学生姓名（模糊匹配） |
| `reviewStatus` | string | `'pending'`待批阅 / `'commented'`已点评 / `'no_ai'`未生成AI评论 |
| `submitTimeBegin` / `submitTimeEnd` | string | 提交时间范围 |
| `pageNum` / `pageSize` | int | 分页 |

**响应 rows 字段**：`recordId`、`taskId`、`taskName`、`creatorType`、`studentId`、`studentName`、`className`、`currentStage`、`status`、`submitTime`、`aiCommented`、`aiCommentVersion`、`reviewStatus`、`teacherCommentBrief`。

### ② GET `/learning/review/detail/{record_id}` —— 批阅详情

**响应**：`{ record, scenario, decisions[], reflections[], research, review }`。其中 `reflections[]` 为按决策拆分的反思列表；`review` 含 `aiComment`（结构化对象）、`teacherComment`、`overallComment`、`reflectionScore`、`reviewStatus` 等。

### ③ POST `/learning/review/ai-comment/{record_id}` —— 生成 AI 评论

**请求体**（可选）：`{ "scope": "reflection" }`（`reflection`仅反思 / `full`含四区）。
**响应**：`{ aiComment: {...}, version, generateTime, reviewModelId }`。
**AI 评论结构**（`aiComment`）：
```json
{
  "summary": "总体评价（1段）",
  "depth_assessment": { "depth_level": "analytical", "score": 0.65, "comment": "..." },
  "strengths": ["..."],
  "weaknesses": ["..."],
  "suggestions": ["..."],
  "theory_reference": [{ "theory_name": "...", "how_applied": "..." }],
  "conclusion": "对学生结论的评论，供老师参考"
}
```
> 前端对该接口单独设 `timeout: 120000`（与伦理分析一致）。

### ④ POST `/learning/review/ai-comment/stream/{record_id}` —— 流式（SSE）

逐行 JSON 事件：`{type:'status'}` → `{type:'result', data:{...}}` 或 `{type:'error', message:'...'}`。

### ⑤ PUT `/learning/review/comment/{record_id}` —— 老师点评

**请求体**：
```json
{
  "reflectionScore": 85,
  "teacherComment": "针对反思结论的点评（submit=true时必填）",
  "overallComment": "总评",
  "aiCommentFeedback": "对AI评论的看法",
  "submit": true
}
```
**响应**：`{ reviewId, reviewStatus }`。点评会联动回写 `edu_evaluation` 的反思维度（仅 record 已 submitted）。

### ⑥ GET `/learning/review/ai-comment-history/{record_id}` —— AI 评论历史

**响应**：`[{ version, aiComment, aiCommentText, scope, modelId, generateTime }]`（version 降序）。

## 四、错误码与权限

- 越权访问非所管学生记录：返回失败，msg=`无权查看/批阅该学生记录`。
- 未配置批阅模型（任务和系统参数都缺）：返回失败，msg=`未配置批阅模型，请联系管理员...`。
- LLM 调用失败：返回失败，msg=`AI评论生成失败，请稍后重试`。

## 六、测试用例

```bash
# 批阅列表（教师视角，仅所管学生）
curl -X GET "http://localhost:8088/learning/review/records?pageNum=1&pageSize=10&reviewStatus=pending" \
  -H "Authorization: Bearer <teacher_token>"

# 批阅详情
curl -X GET "http://localhost:8088/learning/review/detail/2" -H "Authorization: Bearer <teacher_token>"

# 生成 AI 评论（裁判模型，约30-60秒）
curl -X POST "http://localhost:8088/learning/review/ai-comment/2" \
  -H "Authorization: Bearer <teacher_token>" -H "Content-Type: application/json" \
  -d '{"scope":"reflection"}'

# 老师点评
curl -X PUT "http://localhost:8088/learning/review/comment/2" \
  -H "Authorization: Bearer <teacher_token>" -H "Content-Type: application/json" \
  -d '{"reflectionScore":85,"teacherComment":"反思深度较好，建议加强对...","submit":true}'
```
