# 接口变更文档：任务列表接口 - 改造为多角色（admin/教师/学生）

> **版本**：V1.4
> **日期**：2026-06-24
> **变更人**：后端

---

## 一、接口信息

| 项目 | 内容 |
|---|---|
| **接口URL** | `GET /learning/task/list` |
| **接口名称** | 任务列表（多角色：admin/教师/学生） |
| **权限** | admin / teacher / student（不限制角色查看，按角色返回不同范围） |
| **变更类型** | 入参变更（新增多条件查询参数） + 业务逻辑变更（由仅教师扩展为多角色） |

---

## 二、变更内容

### 1. 业务逻辑变更

原 `/list` 接口**仅服务教师**（调用 `get_teacher_tasks`，按 `teacher_id` 查询），其它角色调用得到的也是教师视角的数据。本次按角色丰富为三类视角：

| 角色 | 返回范围 | 是否支持过滤 |
|---|---|---|
| **admin** | 所有班级、所有任务（教师任务 + 学生自研课题），含发布时间，按创建时间降序 | 支持 |
| **teacher** | 自己创建的任务 + 所管班级学生的自研课题（未删除） | 支持 |
| **student** | 当前所属班级指派的任务 + 自己发布的自研课题（一个用户仅归属一个班级） | 按范围展示（与学生任务列表 `/student/list` 一致） |

> 说明：学生分支的展示范围与 `/learning/task/student/list` 保持一致；如需对学生做更丰富的多条件过滤，仍请使用 `/student/list`。

### 2. 入参变更

**变更前**：仅支持 `page_num`、`page_size` 两个分页参数。

```
GET /learning/task/list?page_num=1&page_size=10
```

**变更后**：分页参数不变，新增 12 个可选查询参数（全部为 URL query params，不传则不过滤，**完全向后兼容**）：

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `creator_type` | string | 否 | 任务类型：`'0'`=教学任务，`'1'`=自研课题（精确匹配） |
| `task_name` | string | 否 | 任务名称（模糊匹配） |
| `dept_id` | int | 否 | 归属班级ID（精确匹配） |
| `teacher_name` | string | 否 | 发布教师姓名（模糊匹配） |
| `student_name` | string | 否 | 学生姓名（模糊匹配，匹配自研课题创建者昵称） |
| `task_description` | string | 否 | 任务简述（模糊匹配） |
| `deadline_begin` | string | 否 | 截止时间区间起始，如 `2026-06-01` |
| `deadline_end` | string | 否 | 截止时间区间结束，如 `2026-06-30` |
| `create_time_begin` | string | 否 | 发布/创建时间区间起始，如 `2026-06-01 00:00:00` |
| `create_time_end` | string | 否 | 发布/创建时间区间结束，如 `2026-06-30 23:59:59` |
| `status` | string | 否 | 发布状态：`'0'`=草稿，`'1'`=已发布，`'2'`=已关闭 |
| `page_num` | int | 否 | 当前页码，默认 1 |
| `page_size` | int | 否 | 每页记录数，默认 10 |

> 关于"发布时间"：本系统未单独记录发布动作时间，任务的"发布时间"以 `create_time`（创建时间）为准，对应 `create_time_begin` / `create_time_end` 两个区间参数。

### 3. 出参

**结构无变化**，仍为 `PageModel` 包裹的任务行列表，每行字段与原接口一致（`task_id`、`task_name`、`teacher_name`、`student_name`、`creator_type`、`status`、`assigned_classes`、`create_time` 等）。新增角色（admin/学生）调用时返回结构相同，仅数据范围不同。

## 三、前端需要做的事情

### 1. 角色判断

接口本身按后端 JWT 中的角色自动分发，前端无需在 URL 上标识角色，直接调用即可。

### 2. 任务列表页面增加搜索栏（教师/admin 视图）

在任务管理页面顶部增加查询表单，建议使用 `el-form :inline="true"`：

| 搜索项 | 组件 | 绑定字段 |
|---|---|---|
| 任务类型 | `el-select` | `creator_type`，选项：全部(空) / 教学任务('0') / 自研课题('1') |
| 任务名称 | `el-input` | `task_name` |
| 归属班级 | `el-select` | `dept_id`，选项从班级列表接口获取 |
| 发布教师 | `el-input` | `teacher_name` |
| 学生姓名 | `el-input` | `student_name`（按自研课题创建者筛选） |
| 任务简述 | `el-input` | `task_description` |
| 截止时间 | `el-date-picker type="daterange"` | 拆分为 `deadline_begin` + `deadline_end` |
| 发布时间 | `el-date-picker type="daterange"` | 拆分为 `create_time_begin` + `create_time_end` |
| 发布状态 | `el-select` | `status`，选项：全部(空) / 草稿('0') / 已发布('1') / 已关闭('2') |

### 3. API 调用方式

`api/learning/task.js` 中调用 `/list` 的方法直接将查询参数作为 params 传入即可：

```javascript
// 之前
listTask({ page_num: 1, page_size: 10 })

// 现在（加过滤条件，全部可选）
listTask({
  page_num: 1,
  page_size: 10,
  task_name: '张大爷',
  dept_id: 103,
  student_name: '张',
  create_time_begin: '2026-06-01 00:00:00',
  create_time_end: '2026-06-30 23:59:59',
})
```

### 4. 不需要改的地方

- 返回数据的字段**没有变化**，表格绑定的字段不需要改。
- 分页逻辑**没有变化**。

## 四、测试用例

### 用例1：教师无过滤（验证向后兼容）

```bash
curl -X GET "http://localhost:8088/learning/task/list?page_num=1&page_size=10" \
  -H "Authorization: Bearer <teacher_token>"
```

**预期**：返回该教师自己创建的任务 + 所管班级学生的自研课题，按创建时间降序，与变更前一致。

### 用例2：教师按学生姓名 + 班级组合查询

```bash
curl -X GET "http://localhost:8088/learning/task/list?student_name=张&dept_id=103&page_num=1&page_size=10" \
  -H "Authorization: Bearer <teacher_token>"
```

**预期**：只返回所管班级中、创建者昵称含"张"且分配给班级 103 的任务/课题。

### 用例3：教师按发布时间区间查询

```bash
curl -X GET "http://localhost:8088/learning/task/list?create_time_begin=2026-06-01%2000:00:00&create_time_end=2026-06-30%2023:59:59&page_num=1&page_size=10" \
  -H "Authorization: Bearer <teacher_token>"
```

**预期**：只返回 6 月份创建（发布）的任务。

### 用例4：admin 查看全部

```bash
curl -X GET "http://localhost:8088/learning/task/list?page_num=1&page_size=10" \
  -H "Authorization: Bearer <admin_token>"
```

**预期**：返回系统中所有未删除任务（教师任务 + 学生自研课题）。

### 用例5：admin 按任务类型 + 状态组合查询

```bash
curl -X GET "http://localhost:8088/learning/task/list?creator_type=0&status=1&page_num=1&page_size=10" \
  -H "Authorization: Bearer <admin_token>"
```

**预期**：返回所有已发布的教学任务。

### 用例6：学生查看自己的任务

```bash
curl -X GET "http://localhost:8088/learning/task/list?page_num=1&page_size=10" \
  -H "Authorization: Bearer <student_token>"
```

**预期**：返回当前班级指派的任务 + 自己发布的自研课题。
