# 接口变更文档：学生任务列表 - 新增多条件查询

> **版本**：V1.3
> **日期**：2026-06-11
> **变更人**：后端

---

## 一、接口信息

| 项目 | 内容 |
|---|---|
| **接口URL** | `GET /learning/task/student/list` |
| **接口名称** | 学生任务列表（指派+自研） |
| **权限** | student / teacher / admin |
| **变更类型** | 入参变更（新增查询参数） |

---

## 二、变更内容

### 变更前

接口只支持分页参数，不支持任何过滤：

```
GET /learning/task/student/list?page_num=1&page_size=10
```

### 变更后

新增 10 个可选查询参数，全部为 URL query params，不传则不过滤：

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `creator_type` | string | 否 | 任务类型：`'0'`=教学任务，`'1'`=自研课题 |
| `task_name` | string | 否 | 任务名称（模糊匹配） |
| `dept_id` | int | 否 | 归属班级ID（精确匹配） |
| `teacher_name` | string | 否 | 发布教师姓名（模糊匹配） |
| `task_description` | string | 否 | 任务简述（模糊匹配） |
| `deadline_begin` | string | 否 | 截止时间范围起始，如 `2026-06-01` |
| `deadline_end` | string | 否 | 截止时间范围结束，如 `2026-06-30` |
| `create_time_begin` | string | 否 | 创建时间范围起始，如 `2026-06-01 00:00:00` |
| `create_time_end` | string | 否 | 创建时间范围结束，如 `2026-06-30 23:59:59` |
| `status` | string | 否 | 发布状态：`'0'`=草稿，`'1'`=已发布 |

### 出参

**无变化**，返回数据结构完全不变（rows 里的字段、分页信息都和之前一样）。

## 三、前端需要做的事情

### 1. 任务列表页面增加搜索栏

在 `StudentTaskList.vue`（或对应的任务列表页面）顶部增加查询表单，建议使用 `el-form :inline="true"` 布局：

| 搜索项 | 组件 | 绑定字段 |
|---|---|---|
| 任务类型 | `el-select` | `creator_type`，选项：全部(空) / 教学任务('0') / 自研课题('1') |
| 任务名称 | `el-input` | `task_name` |
| 归属班级 | `el-select` | `dept_id`，选项从班级列表接口获取 |
| 发布教师 | `el-input` | `teacher_name` |
| 任务简述 | `el-input` | `task_description` |
| 截止时间 | `el-date-picker type="daterange"` | 拆分为 `deadline_begin` + `deadline_end` |
| 创建时间 | `el-date-picker type="daterange"` | 拆分为 `create_time_begin` + `create_time_end` |
| 发布状态 | `el-select` | `status`，选项：全部(空) / 草稿('0') / 已发布('1') |

### 2. API 调用方式

现有 `listStudentTask` 方法无需修改，查询参数直接作为 params 传入即可：

```javascript
// 之前
listStudentTask({ page_num: 1, page_size: 10 })

// 现在（加过滤条件）
listStudentTask({
  page_num: 1,
  page_size: 10,
  creator_type: '0',
  task_name: '测试',
  dept_id: 103,
})
```

所有查询参数都是可选的，不传就不过滤，**完全向后兼容**。

### 3. 不需要改的地方

- API 文件 `api/learning/task.js` 中的 `listStudentTask` 方法 **不需要修改**
- 返回数据的字段 **没有变化**，表格绑定的字段不需要改
- 分页逻辑 **没有变化**

## 四、测试用例

### 用例1：无过滤（验证向后兼容）

```bash
curl -X GET "http://localhost:8088/learning/task/student/list?page_num=1&page_size=10" \
  -H "Authorization: Bearer <token>"
```

**预期**：返回全部任务，和变更前完全一致。

### 用例2：按任务类型过滤

```bash
curl -X GET "http://localhost:8088/learning/task/student/list?creator_type=0&page_num=1&page_size=10" \
  -H "Authorization: Bearer <token>"
```

**预期**：只返回 `creator_type='0'` 的教学任务，`source` 字段为 `'teacher'`。

### 用例3：按名称模糊匹配

```bash
curl -X GET "http://localhost:8088/learning/task/student/list?task_name=测试&page_num=1&page_size=10" \
  -H "Authorization: Bearer <token>"
```

**预期**：只返回 `task_name` 包含"测试"的任务。

### 用例4：按班级过滤

```bash
curl -X GET "http://localhost:8088/learning/task/student/list?dept_id=103&page_num=1&page_size=10" \
  -H "Authorization: Bearer <token>"
```

**预期**：只返回分配给班级ID=103的任务（`assigned_classes` 中包含 `dept_id=103`）。

### 用例5：组合查询

```bash
curl -X GET "http://localhost:8088/learning/task/student/list?creator_type=0&status=1&task_name=测试&page_num=1&page_size=10" \
  -H "Authorization: Bearer <token>"
```

**预期**：返回已发布的教学任务中名称包含"测试"的记录。

### 用例6：时间范围查询

```bash
curl -X GET "http://localhost:8088/learning/task/student/list?create_time_begin=2026-06-01&create_time_end=2026-06-30&page_num=1&page_size=10" \
  -H "Authorization: Bearer <token>"
```

**预期**：只返回6月份创建的任务。
