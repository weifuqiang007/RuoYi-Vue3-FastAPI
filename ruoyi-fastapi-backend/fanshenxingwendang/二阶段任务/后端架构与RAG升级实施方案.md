# 二阶段后端架构与 RAG 升级实施方案

> 版本：V1.0  
> 日期：2026-07-28  
> 基线：第一轮后端改造已落地

## 1. 架构边界

### 通用框架 / AI 基建

以下能力应留在 `module_rag`，可被反身性、律师、企业知识库等产品复用：

- 文档解析器、清洗器、分块器及其注册机制
- Embedding 提供方协议及 OpenAI-compatible 适配器
- 向量召回、词法召回、RRF、reranker 与阈值过滤
- 统一的 RAG Context/Citation 构建
- 文档状态机、对象存储、索引版本和离线评测框架

### 反身性领域

以下能力只属于 `module_learning`：

- 四区分别选择哪些知识库
- 如何从情境、决策、反思和批阅数据构造 query
- 反思深度等级、伦理规则、教学评价量表
- 四区 Prompt、任务状态机、教师/学生权限

依赖方向固定为：`module_learning -> module_rag -> common/config`。`module_rag` 不得 import `module_learning`。

## 2. 第一轮已落地

1. Markdown 按标题层级解析，保留 `heading_path`，识别引用、列表、表格、代码和参考文献块。
2. 修复 DOCX 只返回第一个块及段落文字重复提取的问题。
3. 清洗、短块过滤、文档内去重、标题上下文前缀接入处理 Pipeline。
4. 删除文档时同步软删除 chunk。
5. 原 PostgreSQL `simple` 中文全文检索替换为“数据库粗召回 + 中英混合 BM25”。
6. 修复 RRF 排序后丢失融合分数的问题，保留各阶段可解释分数。
7. 新增本地精排器，并提供 Cohere cross-encoder 可插拔适配器。
8. Embedding 改为提供方协议，支持 OpenAI-compatible 服务切换。
9. 四区散落的 RAG 调用收敛到 `RagContextBuilder`，上下文统一带 `[n]` 引用。
10. 修复长段分块末尾重复，并将逐条 flush 改为单次批量 flush。

## 3. Rank 提准方法

不要用主观体验调参。先建立 30～50 条真实问题的金标集，每条至少标：

- 相关 `doc_id/chunk_id`
- 相关性等级（0 不相关、1 可参考、2 直接支持）
- 问题所属区域和术语标签

离线指标采用：

- Recall@5：正确片段能否被召回
- MRR@10：第一个正确片段出现多早
- nDCG@5：多个相关片段的排序质量
- Citation Precision：回答引用是否真的支持论断
- No-answer Accuracy：资料不足时是否拒绝编造

调优顺序固定为：

1. 先测解析/分块是否保留完整语义。
2. 再调粗召回候选数和中英分词。
3. 再比较本地精排、Cohere、本地 BGE reranker。
4. 最后按验证集确定阈值，不允许直接把 `0.3` 当通用常数。

## 4. 后续三批任务

### 第二批：可上线质量

- 给知识库增加 `embedding_model/dimension/index_version` 不变量校验。
- 新增独立的索引任务表，上传接口只落原文和任务，不同步阻塞解析。
- API 返回结构化 citations，生成结果保存引用快照。
- 建立 RAG 离线评测命令和版本对比报告。
- 在真实 PostgreSQL + pgvector 上做删除、权限和混合检索集成测试。

### 第三批：领域提准

- 为社会工作术语增加同义词和标准词映射，但作为 `module_learning` 配置注入。
- 对长反思文本做 query 分解：事件、行动、理由、价值冲突、权力位置分别召回后融合。
- 引入 parent-child：小块负责检索，父章节负责提供完整论证上下文。
- 参考文献块默认降权，用户明确询问文献时再提高权重。

### 第四批：工程化

- HNSW 索引与数据规模基准测试。
- 文档解析/Embedding 的幂等任务、重试、取消和进度。
- 模型调用的超时、熔断、费用、Token 和延迟观测。
- 将通用 AI/RAG 能力提取为版本化模板或独立包，业务项目只装配模块和配置。

## 5. 上线门槛

二阶段不是“接上 reranker”就结束。至少满足：

- 金标集 Recall@5、MRR 不低于当前基线，且有版本报告。
- 已删除文档、越权知识库、低相关内容不会进入生成上下文。
- 每条引用可定位到文档、页码或章节。
- 外部 reranker 失败时能降级，本次请求不整体失败。
- 同一文档重复处理不会累计重复 chunk。
