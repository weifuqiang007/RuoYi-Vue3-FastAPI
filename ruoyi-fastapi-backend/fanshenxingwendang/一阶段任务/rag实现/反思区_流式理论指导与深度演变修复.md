## 二、Bug1：流式生成理论指导

### 2.1 方案（照搬研究生成区流式先例）

```
前端 fetch POST /learning/reflection/questions/stream（绕过 axios 10s 超时）
  → Controller: StreamingResponse(media_type=text/event-stream)
    → Service.generate_questions_stream (AsyncGenerator)
        → yield {"type":"status","message":"AI 正在结合理论生成指导..."}
        → AiCall.call_llm_stream 逐 chunk 转发 → yield {"type":"content","content":"..."}（逐字）
        → 流结束：解析为结构化结果 → 落库（对话+反思+深度历史）
        → yield {"type":"result","data":{...}}
  ← 前端 onContent 逐字更新预览；onResult 渲染结构化卡片
```

### 2.2 Prompt 设计：Markdown + 结尾 JSON 代码块

结构化结果（theory_guidance 等）需可靠解析，但流式又要可读。折中：让 LLM **先输出可读 Markdown**（学生看的指导），**结尾以 ```json 代码块输出结构化结果**（系统解析）。

- 流式预览：前端 `displayStreamText` computed 剥离 ```json 块，只展示可读部分。
- 解析：`_parse_streamed_guidance` 优先取最后一个 ```json 块 → `parse_llm_json`；失败再整体解析；再失败兜底（抽分数 + 正文作 reflection_direction）。

## 三、Bug2：深度演变无内容 + 加说明

### 3.1 根因

`index.vue` 底部 `DepthChart` 用 `allDepthHistory`（聚合自 `tabStates[].depthHistory`）。但：

- `loadData()` 把每个 tab 的 `depthHistory` 初始化为 `[]`；
- 子组件 `DecisionReflectionTab.loadDepthHistory()` 只更新**自己内部**的 `depthHistory`，**从未上报父组件**；
- `onTabSaved` / `onTabGuidanceGenerated` 只更新 score/level/theories，不更新 depthHistory。

→ `allDepthHistory` 恒为 `[]` → 图表永远"暂无数据"。

### 3.2 修复

**深度历史上报链路：**

```
DecisionReflectionTab.loadDepthHistory()
  → emit('depth-loaded', { decisionId, depthHistory })
index.vue onTabDepthLoaded()
  → tabStates[decisionId].depthHistory = history
allDepthHistory (computed) 聚合 → DepthChart 渲染
```

| 文件 | 改动 |
|------|------|
| `DecisionReflectionTab.vue` | `loadDepthHistory()` 末尾 emit `depth-loaded`；新增对应 emits 声明 |
| `index.vue` | 模板绑 `@depth-loaded="onTabDepthLoaded"`；新增 `onTabDepthLoaded` 写入 tabStates |

### 3.3 深度说明（趋势 + 打分依据 + 如何加深）

**`DepthChart.vue`** 在折线图下方新增说明区，全部由 `history` 数据 + 分数阈值**前端计算**（无额外 LLM 调用）：

| 区块 | 内容 |
|------|------|
| 📈 趋势 | 首末分数对比：上升 / 下降 / 平稳 / 首次评估（带具体数值） |
| 🎯 当前层次 | 按分数映射 descriptive/analytical/reflexive + 中文标签 + 分数 |
| 为什么是这个分数 | 反思深度量表三条规则 + 当前层次的一句话解释 |
| 如何继续加深深度 | 按当前层次给出具体深化方向（描述→分析→反身性） |

层次阈值与 `REFLECTION_PROMPT` 一致：
- 描述性 0.20–0.40 / 分析性 0.41–0.70 / 反身性 0.71–1.00

## 四、数据流（生成理论指导全链路）

```
用户点「生成理论指导」
  → generateReflectionQuestionsStream({reflection_id})
    → fetch POST /questions/stream
      → generate_questions_stream:
          校验 → 准备上下文（情境/决策/RAG理论）
          → yield status
          → AiCall.call_llm_stream 逐字 → yield content × N
          → _parse_streamed_guidance → _persist_guidance（对话/反思/深度历史）
          → yield result
  ← onContent: streamText += chunk → 预览区逐字显示
  ← onResult: latestGuidance = data → 渲染理论卡片
            → loadDepthHistory() → emit depth-loaded
              → index.vue 聚合 → DepthChart 更新（趋势/说明）
```

## 五、验证

1. 重启后端 + 前端热更新。
2. 反思区 → 写反思 → 保存 → 点「生成理论指导」：
   - **立即**出现"AI 正在生成..."预览区，内容**逐字**出现（带闪烁光标），不再白屏等待。
   - 生成完成后，预览区消失，结构化理论指导卡片（关联理论/反思方向/追问）渲染。
3. 底部「深度演变」图表：
   - 不再"暂无数据"，折线显示深度变化。
   - 下方显示趋势（数值）、当前层次标签、打分依据量表、如何加深建议。
4. 多次保存/生成后，趋势数值随历史更新（上升/平稳）。
5. 流式中途断网/出错 → 前端弹错误提示，不卡死。
