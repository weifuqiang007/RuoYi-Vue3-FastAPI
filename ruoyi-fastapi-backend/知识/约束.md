要求在在与数据映射的实体类、与前端交互的实体类的时候，要把每一个字段是什么，干什么的，都写清楚。

要求在写数据库sql的时候，要把每一个字段含义写清楚。

写查询接口的时候需要将查询条件确认清楚。可以前期让AI通过接口含义定一些查询参数。后面可以再进行调整。


在每一次改完接口后需要检查一下接口是否发生入参、出参发生改变。如果发生改变，需要记录文档，在文档中明确标明：是什么接口、是什么内容、在哪里发生了改变。最好再加上一个测试用例标明。

## 约束：接口变更必须生成变更文档

当接口的**入参**或**出参**发生改变时，**必须**在 `fanshenxingwendang/接口变更文档/` 目录下创建或更新接口变更文档。

### 文档模板要求

每份接口变更文档必须包含以下内容：

1. **版本号 + 日期**：格式 `VX.Y`，日期格式 `YYYY-MM-DD`
2. **接口信息**：URL、HTTP方法、接口名称
3. **变更类型**：新增接口 / 入参变更 / 出参变更 / 接口废弃
4. **变更内容**：
   - 新增/修改/删除了哪些参数
   - 参数的含义、类型、是否必填
5. **前端需要做的事情**：明确告诉前端工程师需要改什么
6. **测试用例**：给出 curl 或请求示例，方便前端验证


## 约束：Controller 层参数必须使用 Pydantic VO 模型，禁止手写参数列表 + if-else 组装

当接口有多个查询参数（≥3个）时，**必须**在 `entity/vo/` 下创建对应的 Pydantic 查询模型，
并通过 FastAPI 的 `Annotated[QueryModel, Query()]` 自动解析，**禁止**在 Controller 中手写一长串 `Optional` 参数再逐个 `if` 组装。

### ❌ 反面示例（禁止）

```python
@task_controller.get('/student/list')
async def get_student_tasks(
    creator_type: Optional[str] = None,
    task_name: Optional[str] = None,
    dept_id: Optional[int] = None,
    teacher_name: Optional[str] = None,
    # ... 继续写一堆 ...
    page_num: int = 1,
    page_size: int = 10,
) -> Response:
    filters = {}
    if creator_type:
        filters['creator_type'] = creator_type
    if task_name:
        filters['task_name'] = task_name
    # ... 继续一堆 if ...
```

### ✅ 正确做法

**第一步**：在 `entity/vo/xxx_vo.py` 中定义查询模型

```python
class TaskListQueryModel(BaseModel):
    """任务列表查询条件"""
    creator_type: Optional[str] = Field(None, description="任务类型：'0'教学任务 / '1'自研课题")
    task_name: Optional[str] = Field(None, description='任务名称（模糊匹配）')
    dept_id: Optional[int] = Field(None, description='归属班级ID')
    # ... 其他查询字段 ...
```

**第二步**：在 Controller 中用 `Query()` 自动解析

```python
from fastapi import Query

@task_controller.get('/student/list')
async def get_student_tasks(
    request: Request,
    query_db: Annotated[AsyncSession, DBSessionDependency()],
    current_user: Annotated[CurrentUserModel, CurrentUserDependency()],
    query: Annotated[TaskListQueryModel, Query()],
    page_num: int = 1,
    page_size: int = 10,
) -> Response:
    # model_dump(exclude_none=True) 自动过滤掉未传的参数
    filters = query.model_dump(exclude_none=True)
    result = await TaskService.get_student_tasks(
        query_db, current_user.user.user_id, class_id,
        roles=current_user.roles, filters=filters or None,
        page_num=page_num, page_size=page_size,
    )
    return ResponseUtil.success(data=result)
```

### 核心要点

1. **查询参数≥3个时必须用 VO**：少量参数（1-2个）可以直接写在函数签名中，超过3个必须创建 QueryModel
2. **VO 字段必须写 description**：用 `Field(None, description='...')` 标注每个字段含义
3. **Controller 中一行搞定**：`Annotated[QueryModel, Query()]` 让 FastAPI 自动解析 URL query params
4. **用 `exclude_none=True` 过滤**：`query.model_dump(exclude_none=True)` 只保留用户实际传入的字段
